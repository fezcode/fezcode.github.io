piml ↗

piml is a data serialization format designed to be exceptionally human-readable and writable, while maintaining a clear and unambiguous structure for machine parsing. Spec v1.2.0 is implemented by three official libraries - go-piml, piml.js and piml.net - plus a tree-sitter grammar, all validated against one shared compliance suite.
