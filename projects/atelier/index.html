III · NEW IN 0.4.0

Photos stand up straight now.

Avalonia’s decoder ignores the EXIF orientation tag, so a portrait phone photo always opened on its side. Atelier 0.4.0 models all eight EXIF values and every rotate and flip as one value; the tag is only where it starts. Saving bakes the turn into the pixels and clears the tag.

R

Rotate and flip

R and Shift+R turn the picture; flip it horizontally or vertically from Edit. Nothing touches the disk until you save.

CtrlC

Copy three ways at once

Pixels, the file and its path, all together — it pastes into an editor, an Explorer window or a text box alike.

CtrlV

Open from the clipboard

Paste a copied file or loose pixels straight into the viewer; a copied file wins.

F2

Rename in place

Type a bare name and the extension is kept for you.

Del

Recycle Bin, never gone

Delete moves the picture to the Recycle Bin and shows the next one. There is no permanent delete, so a mis-tap is always recoverable.

Space

Animated GIF and WebP

They play at their own frame delays and Space pauses. A very long animation falls back to a still first frame instead of filling memory.

Ctrl0

Fit, actual size, steps

Ctrl+0 fits, Ctrl+1 is 100%, Ctrl+plus and minus step the zoom.

CtrlS

Save bakes the turn in

Saving writes the rotation into the pixels and clears the tag, or the next open would turn it again. Save As moved to Ctrl+Shift+S.

IV · FILE › SET AS WALLPAPER

Put it on the wall.

Set as Wallpaper offers Fill, Fit, Stretch, Centre, Tile and Span, converting SVG, HEIC, AVIF, WebP and ICO first — Windows itself only accepts JPG, PNG and BMP.

V · FORMATS

Whatever the folder throws at it.

SVG is rendered as vector, not as a rasterized preview, so zoom stays sharp at any magnification. HEIC and HEIF from a phone open directly through Magick.NET, alongside AVIF, WebP and ICO.
