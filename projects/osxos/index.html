04 / THE OPERATING PRINCIPLES

Less mystery.
More agency.

Rights, precisely scoped.

The application normally runs as you. Tools that need administrator rights declare them and elevate the particular command, rather than the whole application.

A report can be the whole job.

Read-only tools say so. A job with nothing useful to do says so. The result records skipped files and unsuccessful steps alongside successful ones.

A machine that stays local.

osXos makes no network requests. Settings live in a plain JSON file. The application tells you where that file is and opens the folder for you.
