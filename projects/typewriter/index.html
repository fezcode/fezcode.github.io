6A distraction-free editor with the soul of a mechanical
7typewriter. Recorded key strikes are embedded in the binary, the
8paper is warm, and there is nothing in the window but the page.
9 
10v0.4.0 | Windows / macOS / Linux | C / SDL2 / FreeType
11 
12Download the binaryRead the source
13 
14There is no sidebar, no minimap, and no status bar full of
15extensions. There is a page, and the sound of typing on it —
16recorded mechanical strikes with concurrent playback, so fast
17typing sounds like fast typing.
18 
19One C file, near-zero CPU at idle, and a single self-contained
20executable: sounds, icon and the typewriter face are all
21embedded, and SDL2 links in statically.
22 
23WHAT IT DOES
24----------------------------------------------------------------
25 
26* Real typewriter sounds
27 Recorded key strikes compiled into the binary as headers, with
28 overlapping playback for a genuinely tactile feel.
29 
30* Paper themes
31 Classic Cream, Dark Mode and Terminal Green, with optional
32 coffee rings, ink spills and creases drawn procedurally.
33 
34* Find and replace
35 A custom dialog in keeping with the rest of the machine,
36 rather than a system one.
37 
38* Undo
39 A 512-entry history, so a bad paragraph is never final.
40 
41* Settings that persist
42 Sounds, line numbers and theme are saved to typewriter.ini
43 beside the executable.
44 
45* Hisashi menu bar
46 With Hisashi running, File / Edit / View / Help appear in its
47 menu bar with every option and shortcut. Off by default.
