# Apps that speak hoswl

The OS Window Layer is a named pipe and a handful of JSON messages. Any app can publish its menus into Hisashi's macOS-style bar — these already do.

description: File / Playback / Audio / View / Help, with live checkmarks for shuffle, repeat and always-on-top.

:::
