# What it looks like in practice

## One entry, several platforms

A game you bought on Steam years ago and picked up again in an Epic giveaway is one tile, not two. The detail pane carries both marks, and the launch button asks which platform you meant only when it genuinely matters.

## Themes

Five editorial palettes and seven typefaces, switchable live — the library is a room you spend time in, so it should look like somewhere you chose.
