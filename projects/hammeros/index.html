03 / TOOLS ISSUED TO PERSONNEL

Useful work.
Unusual surroundings.

A proper workspace underneath the institution. Open your documents, arrange your applications, and give every task a place to live.

01 / HOST

A terminal with a real connection.

Independent, unelevated PowerShell and CMD sessions run through Windows ConPTY, with a VT engine from Clockt. Tabs have their own processes, names, and working directories.

Closing Terminal ends its sessions. Minimizing preserves them.
02 / RECORDS

The files are your files.

Browse actual drives alongside the fictional Department drive. Folder tabs, previews, UTF-8 editing, copy and move queues, recycling, and Terminal here keep everyday work close.

Your Windows files stay on your Windows filesystem.
03 / WINDOWS

Bring your applications inside.

The tiled workspace can launch or attach compatible Windows application windows. Arrange them in grids, rows, columns, or a focused view. Detach returns them to Windows.

Compatibility depends on the application. HammerOS remains a Windows app.
04 / CONTINUITY

A place for every line of work.

Create up to nine desktops, move windows between them, and save workspace profiles. Session restoration remembers layouts, folders, browser tabs, and unsaved text drafts.

Shell processes start fresh; commands are never replayed on restart.
