PICK UP WHERE YOU LEFT OFF

A window closes.
Your work lives on.

Published builds run shells in a separate session host, outside the installation folder. Close a window and the shells keep running; update clockt and the new UI reattaches to the sessions the old one left behind.

MADE FOR THE WAY YOU BUILD

Find your flow.

The small details that make a terminal feel like your own.

Detachable sessions

window.closeAction decides what closing means: ask, detach, or kill. Detach the whole window deliberately and pick it up from any console.

ctrl+shift+alt+d

Workspaces

Group tabs into named workspaces in the sidebar — collapse, rename inline, drag tabs between them.

ctrl+shift+g

Tabs and splits

Split right or down, focus and resize with alt and the arrows, zoom a pane, and get the whole layout back on the next launch.

ctrl+shift+d

Developer panels

Project tasks for CMake/Ninja, Go, .NET, Maven/Gradle and JS/TS, plus a command timeline, a Problems panel and an agent dashboard.

ctrl+alt+j

Browser pane

An embedded WebView2 beside your shells, scriptable with navigate, js and dom.

Fourteen themes

The ANSI palette, cursor, selection, tab pills and pane borders are all tokens — the terminal is themed, not just the chrome around it.

Explore the CLI & automation

Install clockt, then make your first session.

clockt / command line
# create a session and attach❯ clockt new -n build
# list daemon sessions❯ clockt ls
# type into a session❯ clockt send build "npm test"
# print its screen❯ clockt read build
# drive the window from a script❯ clockt cmd pane.split.right
# hosts from ~\.ssh\config❯ clockt ssh dev

ROOM TO MAKE IT YOURS

Your very own toolbox.

Status bar plugins are .ckt bundles loaded into isolated AssemblyLoadContexts behind a permission gate; four ship in the box — sessions, working directory, git and clock. Implement IClocktPlugin and IStatusWidget against Clockt.Sdk and pack with tools/ckt-pack.

For scripts and agents, clockt ls --json | read | send | rename | cmd | browser drives sessions and windows from the outside, including screenshots and workspace creation.
